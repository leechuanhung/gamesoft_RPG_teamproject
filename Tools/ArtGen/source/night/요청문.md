# 콩밭 마을 하룻밤 연출, GPT 그림 요청문

> 이 폴더의 A1~F1, S는 아래 요청으로 받은 그림이다(화면 캡처). `make_night.py`가 잘라 `18_Night`를 만든다.
> 구도 참고용 `guide_…png`는 예전 그림으로 만든 것이라 지웠다. 컷을 다시 뽑을 때는 지금 그림을 구도 참고로 첨부한다.
> 캡처 말고 다운로드한 원본을 저장하고, 편집을 요청할 때도 원본을 첨부해야 위아래 띠가 따라오지 않는다.

## 원리

연출은 영상이 아니에요. **정지 그림 몇 장을 바꿔 끼우고 일부만 움직이는 방식**이에요.
그래서 GPT에게는 컷마다 **정지 그림**만 받으면 돼요. 움직임은 제가 코드로 만들어요.

- 바뀌는 순간(불이 꺼짐, 선비가 일어나 앉음, 구멍이 뚫림, 눈이 뜨고 감김, 닭이 욺)은 **같은 그림을 편집한 버전**으로 받아요.
  바뀐 부분만 제가 잘라서 겹치니, 편집할 때 나머지가 조금 달라져도 괜찮아요.
- 반딧불, 먼지, 구름, 안개, 그림자가 미끄러져 들어오기, 화면 전환, 자막은 제가 코드로 처리해요. 그림에 넣지 마세요.
- 콩쥐 눈 클로즈업(`kongjwi_stare_cut.webp`)과 대화 초상화는 이미 GPT 그림이라 그대로 써요.

## 진행 방법

1. **채팅방 하나에서** 아래 0번부터 차례로 보내요. 그래야 그림체가 유지돼요.
2. `guide_…png`는 지금 게임에 있는 그림이에요. 구도를 잡는 참고용으로만 첨부해요(그림체는 따라 하지 말라고 요청문에 써 두었어요).
3. **편집** 표시가 있는 요청은 바로 앞에서 받은 그림을 꼭 다시 첨부해요.
4. 받은 그림은 `Tools/ArtGen/source/night/` 폴더에 표의 파일 이름으로 저장해요. 확장자는 상관없어요(png, webp, jpg).
5. 비율은 가로 16:9로 요청해요. 3:2로 나오면 위아래를 제가 조금 잘라요. 그러니 중요한 건 가운데에 오게 해 주세요.
6. 대화가 길어져 그림체가 흐트러지면, 새 채팅에서 0번을 다시 보내고 지금까지 받은 그림 1~2장을 같이 첨부해요.

## 0. 그림체와 인물 고정 (그림 없이 시작)

```
이 대화에서 게임 컷씬 그림을 여러 장 그릴 거야. 첨부한 콩쥐·팥쥐 초상화와 콩쥐 눈 클로즈업이 기준 그림체야.
앞으로 그리는 그림은 전부 이 그림체로 통일해 줘.

그림체
- 애니메이션풍 픽셀 아트. 또렷한 도트, 어두운 외곽선, 풍부한 색 단계와 빛 표현
- 배경은 조선 시대 시골 마을(기와집, 장독대, 돌담, 창호지 문)
- 한 장이 게임 화면 전체를 채우는 가로 16:9 와이드 그림
- 글자, 말풍선, 효과음 글씨, 테두리, 서명은 절대 넣지 않기

등장인물(모든 그림에서 같은 모습으로)
- 선비: 20대 초반 남자, 수염 없음, 검은 머리, 흰 도포, 길게 늘어진 남색 띠, 검은 갓, 흰 버선. 첨부한 게임 캐릭터 그림 참고
- 콩쥐: 긴 갈색 웨이브 머리, 분홍 꽃 머리장식과 분홍 리본, 노란 저고리, 분홍 고름, 붉은 치마, 붉은 눈. 겉으로는 상냥하게 웃는다
- 팥쥐: 짙은 남보라색 머리를 한 갈래로 길게 땋고 빨간 댕기, 초록 저고리, 보라 고름, 남색 치마. 겉으로는 사납다

이야기: 과거 보러 가던 선비가 콩쥐네 집에서 하룻밤 묵는다. 밤에 정체 모를 괴물이 손님방 문 밖에 와서
창호지에 구멍을 뚫고 안을 들여다본다. 저녁은 따뜻하지만 어딘가 불길하고, 밤은 서늘하고 으스스하다.

앞으로 "구도 참고"라고 첨부하는 그림은 배치와 크기만 따르고, 그림체는 절대 따라 하지 마.
"편집"이라고 하면 첨부한 그림에서 말한 부분만 바꾸고 나머지는 최대한 그대로 둬.
이해했으면 그림은 그리지 말고 "준비됐어"라고만 답해 줘.
```

## A1. 노을 진 집 앞

```
[구도 참고] 첫 번째 장면: 해 질 녘, 콩쥐네 집 앞.
첨부한 그림과 같은 배치로 그려 줘.
- 화면 왼쪽 절반에 기와집. 툇마루와 창호지 문 세 칸. 왼쪽 아래에 장독대 항아리들, 왼쪽 끝에 감이 달린 감나무
- 집 뒤로 낮은 돌담과 겹겹이 이어진 산
- 하늘은 보라에서 주황으로 넘어가는 노을. 해가 산 너머로 지는 중
- 화면 오른쪽 흙길 위에 왼쪽부터 선비, 콩쥐, 팥쥐가 서 있다. 전신, 작게(화면 높이의 1/4 정도), 서로 마주 보는 느낌
- 인물에게 노을빛이 비치고 그림자가 길게 늘어진다
```

## A2. (편집) 팥쥐가 움츠림

```
[편집] 방금 그림에서 팥쥐만 바꿔 줘. 팥쥐가 반걸음 뒤(오른쪽)로 물러나 어깨를 움츠리고 고개를 숙였다.
집, 하늘, 선비, 콩쥐는 그대로.
```

## B1. 달밤의 집

```
[구도 참고] 같은 집의 그날 밤. 배치는 첫 번째 첨부 그림, 집과 장독대와 감나무의 모양은 두 번째 첨부 그림(저녁 장면)과 같게.
- 오른쪽 위에 보름달, 별, 달 앞을 지나는 옅은 구름
- 전체가 푸른 달빛. 사람은 없다
- 집의 가장 오른쪽 창호지 문 한 칸에만 따뜻한 주황 등잔불이 켜져 있고, 그 불빛이 툇마루에 조금 번진다
```

## B2. (편집) 불 꺼짐

```
[편집] 방금 그림에서 불 켜진 창호지 문의 등잔불만 꺼 줘. 그 칸도 다른 칸처럼 어둡고 푸르게. 나머지는 그대로.
```

## C1. 손님방, 밤

```
[구도 참고] 손님방 안, 같은 날 밤. 첨부한 그림과 같은 배치로.
- 왼쪽 벽에 산수화 병풍. 가운데 횃대에 갓과 도포가 걸려 있고, 그 아래 작은 서안 위에 꺼진 등잔
- 오른쪽 벽에 큰 창호지 미닫이문(문살 격자). 문 밖에서 푸른 달빛이 비쳐 창호지가 은은하게 빛나고, 바닥에 문살 모양 빛이 비스듬히 떨어진다
- 왼쪽 아래에 요를 깔고 이불을 덮은 선비가 목침을 베고 잠들어 있다. 갓은 벗었고 상투가 보인다
- 방은 어둡고 서늘한 남색. 조용하다. 문에 그림자는 아직 없다
```

## C2. (편집) 선비가 일어나 앉음

```
[편집] 방금 그림에서 선비만 바꿔 줘. 이불을 덮은 채 상체를 일으켜 앉아, 오른쪽 문을 놀라고 긴장한 얼굴로 바라본다.
방, 문, 달빛은 그대로.
```

## S. 괴물 그림자 실루엣

```
그림체 예외: 이번 그림은 흰 배경 위에 새까만 단색 실루엣만. 음영, 디테일, 배경, 외곽선 없이.
창호지 문에 비치는 괴물의 그림자야. 커다란 독(항아리) 같은 둥근 몸통 위에 두꺼비 머리가 박혀 있고, 가늘고 긴 팔이 두 개 있다.
흰 배경에 서로 떨어지게 4개를 가로로 나란히 그려 줘.
1) 두 팔을 아래로 늘어뜨리고 서 있다
2) 한 손을 입 쪽으로 가져가 무언가를 먹으려 한다
3) 그 손이 입에 닿아 무언가를 씹고 있다
4) 같은 괴물의 머리와 어깨만 아주 가까이서 본 모습, 크게. 툭 튀어나온 두 눈의 윤곽이 보인다
1~3번은 크기, 위치, 몸통 모양이 똑같고 팔만 달라야 해.
```

괴물 모양은 지금 게임에 있는 것(독에 박힌 두꺼비)을 그대로 적었어요. 바꾸고 싶으면 이 문장만 고치면 돼요.

## D1. 창호지 문 클로즈업

```

- 밖에서 달빛이 비쳐 창호지가 푸르스름하게 빛난다. 종이의 결과 얼룩이 보인다
```
